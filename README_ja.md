# Page Flow for Obsidian (日本語マニュアル)

Obsidian 内のノート閲覧・トリアージ（仕分け・検品）を極限まで快適にするプラグインです。単一のホットキー操作で画面単位のページ送りと、ノート末尾到達時の次ファイルへのシームレスな移動を実現します。

[English README](README.md)

---

## ✨ 主な機能

- **ハイブリッド・ページ送り（スクロール または 次/前のファイルへ）**:
  - 設定した割合（デフォルト: 85%）ずつノート内を滑らかに画面スクロール。
  - ノートの最下部に到達した状態で再度ホットキーを押すと、同一フォルダ内の「次のファイル」を自動で開きます。
  - 逆方向も完全対称に動作: 最上部でホットキーを押すと直前のファイルが「最下部を表示した状態」で開きます。
- **動的連打加速（Dynamic Chained Acceleration）**:
  - スクロール時間を長め（例: 600ms）にしてじっくり斜め読みしている時でも、キーをポンポン連打すると打鍵数に応じて自動で加速（最速 150ms まで短縮）。
  - キーを離せばピタッと滑らかに止まり、次回は再び設定通りのゆったり速度で動き出します。
- **独立コマンドの提供**:
  - `1ページ下にスクロール` / `1ページ上にスクロール`: ファイル移動を行わない純粋なスクロール。
  - `フォルダ内の次のファイルへ移動` / `フォルダ内の前のファイルへ移動`: スクロール位置に関わらず即座にファイル移動。
- **柔軟な設定**:
  - スクロール量（50%〜100%）
  - スムーズスクロールの ON / OFF および所要時間（100ms〜1,000ms）
  - ファイルの並び順（ファイル名昇順/降順、作成日時順、更新日時順）
  - フォルダ末尾到達時のループ移動

## ⌨️ おすすめのホットキー設定

**設定 > ホットキー** で以下の割り当てがおすすめです：

- **進む: 下にスクロール または 次のファイルへ**: `Alt + Space`（または `Page Down`, `Alt + J`）
- **戻る: 上にスクロール または 前のファイルへ**: `Alt + Shift + Space`（または `Page Up`, `Alt + K`）
- **フォルダ内の次のファイルへ移動**: `Alt + Down`
- **フォルダ内の前のファイルへ移動**: `Alt + Up`

## 🛠️ 開発環境（Docker 完全コンテナ隔離）

ビルドおよびテストはすべて Docker コンテナ内で実行します：

```bash
# プロダクションビルド (main.js)
docker compose run --rm page-flow npm run build

# 自動単体テスト (Vitest)
docker compose run --rm page-flow npm test

# 開発用ウォッチモード
docker compose run --rm page-flow npm run dev
```
